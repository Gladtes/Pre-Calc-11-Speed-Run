Unit 1

Factoring and Rational Functions

Big idea: Factoring means breaking an expression into a product of smaller pieces multiplied together — basically "unmultiplying." It's the key tool for simplifying fractions that have variables in them (rational functions).

Factoring Review

Factoring rewrites an expression as a product of simpler expressions. The main techniques are:

  • Greatest Common Factor (GCF): pull out what every term shares.
  • Difference of squares: a² − b² = (a − b)(a + b)
  • Trinomial factoring: find two numbers that multiply to "ac" and add to "b" for ax² + bx + c
  • Sum/difference of cubes: a³ ± b³ = (a ± b)(a² ∓ ab + b²)
  • Grouping: factor pairs of terms separately, then factor out the common binomial
Example: Factor x² − 5x − 14.
Find two numbers that multiply to −14 and add to −5 → −7 and 2.
x² − 5x − 14 = (x − 7)(x + 2)

Rational Functions

A rational function is a fraction of two polynomials, f(x) = P(x)/Q(x). To understand its behavior, factor both the numerator and denominator.

  • Vertical asymptotes occur where the denominator equals zero (and doesn't cancel with the numerator).
  • Holes occur where a factor cancels from both the top and bottom.
  • Horizontal asymptotes depend on the degree of the numerator vs. the denominator (compare leading terms).
  • Simplify by canceling common factors — but remember the original domain restriction still applies!
Example: f(x) = (x² − 9)/(x² − x − 12)
Factor: (x − 3)(x + 3) / (x − 4)(x + 3)
The (x + 3) cancels → hole at x = −3. Vertical asymptote at x = 4 (from the remaining denominator factor).

Check Your Understanding

1. Factor completely: 2x² + 7x + 3

Show answer
Find two numbers that multiply to (2)(3) = 6 and add to 7 → 6 and 1.
2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3)

2. For g(x) = (x + 5)/(x² + 2x − 15), identify any holes and vertical asymptotes.

Show answer
Factor the denominator: x² + 2x − 15 = (x + 5)(x − 3).
g(x) = (x + 5) / [(x + 5)(x − 3)] → the (x + 5) cancels, giving a hole at x = −5.
The remaining denominator factor (x − 3) gives a vertical asymptote at x = 3.
Unit 2

Real Numbers, Powers and Radicals

Big idea: This unit is about the "toolbox" numbers — how exponents (powers) and roots (radicals) behave, and how to simplify expressions that use them.

The Real Number System

Real numbers include rational numbers (integers, fractions, terminating/repeating decimals) and irrational numbers (non-repeating, non-terminating decimals like √2 or π). Basically, if you can put it on a number line, it's a real number.

Exponent Rules

  • Product rule: aᵐ · aⁿ = aᵐ⁺ⁿ
  • Quotient rule: aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • Power rule: (aᵐ)ⁿ = aᵐⁿ
  • Negative exponent: a⁻ⁿ = 1/aⁿ
  • Zero exponent: a⁰ = 1 (a ≠ 0)
  • Fractional exponent: a^(m/n) = ⁿ√(aᵐ)
Example: Simplify (2x³y⁻²)² ÷ x⁴
= 4x⁶y⁻⁴ ÷ x⁴ = 4x²y⁻⁴ = 4x² / y⁴

Radicals

A radical √a asks "what number, squared (or cubed, etc.), gives a?" Radicals can be simplified by pulling out perfect powers, and rationalized by removing radicals from the denominator.

Example: Simplify √72.
72 = 36 × 2, and 36 is a perfect square.
√72 = √36 · √2 = 6√2
Example: Rationalize 5 / √3.
Multiply top and bottom by √3: (5√3) / 3

Check Your Understanding

1. Simplify: (3a²b)⁻² · a⁵

Show answer
(3a²b)⁻² = 1/(9a⁴b²)
So the expression becomes a⁵ / (9a⁴b²) = a / (9b²)

2. Simplify √50 + 3√2 (write as a single simplified radical term).

Show answer
√50 = √25 · √2 = 5√2
5√2 + 3√2 = 8√2
Unit 3

Quadratics and Inequalities

Big idea: A quadratic is any equation with an x² term — its graph is a parabola. This unit is about finding where that parabola crosses zero (solving) and where it's above or below zero (inequalities).

Solving Quadratics

A quadratic equation is ax² + bx + c = 0. There are three common solving methods:

  • Factoring — fastest when the expression factors nicely.
  • Completing the square — turns the equation into vertex form.
  • Quadratic formula: x = [−b ± √(b² − 4ac)] / (2a) — always works.

The discriminant, b² − 4ac, tells you the number and type of solutions:

  • Positive → two real solutions
  • Zero → one real (repeated) solution
  • Negative → two complex solutions
Example: Solve x² − 4x − 5 = 0.
Factor: (x − 5)(x + 1) = 0 → x = 5 or x = −1

Quadratic Inequalities

To solve a quadratic inequality like x² − x − 6 > 0:

  • Factor and find the boundary points (roots): (x − 3)(x + 2) = 0 → x = 3, x = −2
  • Plot these on a number line — they split it into three intervals.
  • Test a point in each interval to see if it satisfies the inequality.
  • Write the solution using the intervals that work.
Example: Solve x² − x − 6 > 0.
Roots: x = 3, x = −2. Testing intervals shows the inequality holds for x < −2 or x > 3.
Solution: x ∈ (−∞, −2) ∪ (3, ∞)

Check Your Understanding

1. Use the discriminant to determine the number/type of solutions for 2x² + 3x + 5 = 0.

Show answer
b² − 4ac = (3)² − 4(2)(5) = 9 − 40 = −31
Since the discriminant is negative, there are two complex (non-real) solutions.

2. Solve the inequality x² − 2x − 8 ≤ 0.

Show answer
Factor: (x − 4)(x + 2) = 0 → roots x = 4, x = −2
Since the parabola opens upward and we want ≤ 0 (below or on the x-axis), the solution is the interval between the roots:
−2 ≤ x ≤ 4
Unit 4

Trigonometry

Big idea: Trigonometry connects angles to side lengths (in triangles) and to coordinates (on the unit circle), which lets you describe repeating, wave-like patterns.

Right Triangle Trig (SOH-CAH-TOA)

  • sin(θ) = opposite / hypotenuse
  • cos(θ) = adjacent / hypotenuse
  • tan(θ) = opposite / adjacent

The Unit Circle

On the unit circle (radius 1), the coordinates of any point at angle θ are (cos θ, sin θ). Key angles to memorize: 0°, 30°, 45°, 60°, 90°, and their radian equivalents (0, π/6, π/4, π/3, π/2).

Example: Find sin(30°) and cos(30°).
sin(30°) = 1/2, cos(30°) = √3/2

Trig Identities

  • Pythagorean identity: sin²θ + cos²θ = 1
  • tan(θ) = sin(θ) / cos(θ)
  • Reciprocal identities: csc θ = 1/sin θ, sec θ = 1/cos θ, cot θ = 1/tan θ

Graphing Sine and Cosine

For y = A·sin(Bx + C) + D or y = A·cos(Bx + C) + D:

  • Amplitude = |A| (height from midline to max/min)
  • Period = 2π / |B| (length of one full cycle)
  • Phase shift = −C/B (horizontal shift)
  • Vertical shift = D (moves the midline up/down)
Example: For y = 3sin(2x) + 1, the amplitude is 3, the period is 2π/2 = π, and the midline is y = 1.

Check Your Understanding

1. If sin(θ) = 3/5 and θ is in Quadrant I, find cos(θ).

Show answer
Use sin²θ + cos²θ = 1 → (3/5)² + cos²θ = 1 → cos²θ = 1 − 9/25 = 16/25
cos(θ) = 4/5 (positive, since θ is in Quadrant I)

2. State the amplitude, period, and vertical shift of y = 4cos(x/2) − 2.

Show answer
Amplitude = |4| = 4
Period = 2π / (1/2) = 4π
Vertical shift = −2 (midline is y = −2)
